# Shopflow Admin

A React and TypeScript admin dashboard for managing an ecommerce storefront. The app is built with Vite and includes dashboard views, localized interface text, and browser-based data persistence.

## Requirements

- Node.js compatible with the installed Vite version
- Yarn or npm

## Getting started

Install dependencies with Yarn:

```sh
yarn install
```

Or use npm:

```sh
npm install
```

Start the development server:

```sh
yarn dev
```

For npm, use `npm run dev`. Vite prints the local URL in the terminal.

## Scripts

- `yarn dev` — start the Vite development server (`npm run dev`)
- `yarn build` — create a production build in `dist/` (`npm run build`)
- `yarn lint` — run the configured build check (`npm run lint`)
